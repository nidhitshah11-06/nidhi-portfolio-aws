# Nidhi Shah — Portfolio

A React + Vite personal portfolio with an interactive Tech Vault terminal.

## Run locally

npm install
npm run dev

## Production build

npm run build
npm run preview

## Before publishing

1. Replace your-email@example.com in Contact.jsx.
2. Verify repository URLs in projects.js.
3. Verify internship title and achievements.
4. Add your own profile image if required.
5. Run npm run build and test on desktop and mobile.

## AWS Amplify

Connect the GitHub repository to AWS Amplify Hosting.

npm run build
